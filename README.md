# Neerakrit-Agrosense-Drone
Neerakrit is an AI-powered multipurpose hexacopter designed for precision agriculture, crop monitoring, disease detection, surveillance, and mapping. Built with Pixhawk, ArduPilot, Raspberry Pi, GPS, telemetry, and YOLOv8n, it integrates AI-based vision with a high-pressure spraying system for targeted agricultural applications.
